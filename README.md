# code-and-chill ☕️

Đây là repository cá nhân dùng để rèn luyện tư duy giải quyết vấn đề, thuật toán và cấu trúc dữ liệu bằng Go.

Project được tạo ra với mục tiêu học đều đặn, hiểu sâu bản chất vấn đề và cải thiện kỹ năng coding theo thời gian — không đặt nặng tốc độ hay thành tích.

---

## Mục tiêu

- Rèn luyện tư duy logic và problem solving
- Nâng cao kiến thức thuật toán và cấu trúc dữ liệu
- Thành thạo Go (Golang) thông qua thực hành
- Duy trì thói quen code đều đặn, lâu dài

---

## 🛠 Công nghệ sử dụng

- **Ngôn ngữ:** Go (Golang)
- **Trọng tâm:** Thuật toán, cấu trúc dữ liệu, giải pháp rõ ràng và dễ hiểu

---

## 🧠 Cách tiếp cận

Mỗi bài toán được giải với định hướng:
- Ưu tiên tính đúng đắn và dễ đọc
- Có chú thích giải thích ý tưởng chính
- Tối ưu dần theo mức độ hiểu biết
